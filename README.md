🚦 Cooperative Smart Traffic Management System Using Multi-Agent Reinforcement Learning

📌 Project Overview

This project presents a Cooperative Smart Traffic Management System designed to improve traffic flow across multiple intersections using Artificial Intelligence and Multi-Agent Reinforcement Learning.

The system uses SUMO (Simulation of Urban MObility) to simulate road traffic and explores the use of Multi-Agent Proximal Policy Optimization (MAPPO) to coordinate traffic signal decisions across multiple intersections.

🎯 Project Objectives

- Improve traffic flow at multiple intersections.
- Reduce vehicle waiting times and unnecessary congestion.
- Coordinate traffic signals using cooperative decision-making.
- Apply Multi-Agent Reinforcement Learning to traffic management.
- Evaluate traffic performance through simulation.

🧠 Methodology

The project explores a multi-agent approach in which traffic intersections are controlled cooperatively.

Key Concepts

- Multi-Agent Reinforcement Learning (MARL): Enables multiple agents to learn traffic control policies.
- MAPPO: A reinforcement learning algorithm used to train cooperative agents.
- Centralized Training and Decentralized Execution (CTDE): A learning framework for coordinating multiple agents.
- SUMO Simulation: Provides a simulated traffic environment for testing and evaluation.
